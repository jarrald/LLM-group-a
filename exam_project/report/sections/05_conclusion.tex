\section{Conclusion}
StudyGraph meets the MVP's technical aim: a local Ollama model generates answers from a persistent Streamlit/LangGraph application, Chroma supplies traceable course passages, and the 4T's are concrete, configurable prompt inputs (RQ1). The archived numerical comparison gives the expected specialist-versus-generalist result: linear regression substantially outperformed LLM+RAG on the same three inputs, although retrieval reduced error relative to no-RAG generation (RQ2). The later controlled experiment found no runnable small-model programs and no valid prediction MAE; together with the historical observations, it shows that relevant retrieval and visible reference are not equivalent to effective use (RQ3). Our strongest conclusion is therefore methodological as well as technical: RAG is useful infrastructure for grounding, but claims about its value require controlled configurations and outcome measures matched to the task.
