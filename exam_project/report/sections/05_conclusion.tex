\section{Conclusion}
StudyGraph uses Ollama to run a local LLM, Chroma to retrieve course passages, and the 4T's to shape its answers. These features provide course-specific study support with inspectable sources (RQ1). In the archived exploratory numerical comparison, linear regression achieved MAE 13.28, while the local LLM with RAG achieved 107.15 on the same three inputs. RAG reduced error relative to no-RAG generation, but regression was much more accurate (RQ2). In the later controlled experiment, none of the six generated programs ran. The smaller local LLMs therefore did not produce working regression code, with or without retrieved documentation (RQ3). The project shows both the practical value of local models and RAG and their limits. Claims about their value require controlled settings and measures that match the task.
