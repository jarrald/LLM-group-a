\section{Linear regression versus local LLM + RAG}
\subsection{Required numerical comparison: archived exploratory evidence}
The only recorded experiment that directly answers the assignment's same-input prediction exercise is the archived run of 9 November 2026. We include it as \textbf{historical/exploratory evidence}, not as the later controlled small-model experiment. The 500-row ice-cream dataset maps \texttt{Temperature} to \texttt{Revenue}. Two calls to \texttt{train\_test\_split} with \texttt{random\_state=42} first hold out 75 test rows (15\%), then take 64 of the remaining 425 rows (15\% of the remainder) for validation, leaving 361 training rows. The actual train/validation/test shares are 72.2\%/12.8\%/15.0\%. Three test inputs were selected: coldest, median, and warmest. Their targets were withheld from both prediction approaches until scoring.

Scikit-learn's \texttt{LinearRegression} was fitted on the 361 training rows only, giving
\begin{equation}
\widehat{\mathrm{Revenue}}=21.2581\,\mathrm{Temperature}+49.8138.
\end{equation}
The LLM used \model{qwen2.5-coder:7b} via Ollama, temperature 0 and context 4096. Its RAG collection contained only 12 evenly spaced \emph{training} reference rows embedded with \model{nomic-embed-text}; the three nearest reference rows by embedding distance accompanied each question. It received exactly the same test temperatures as regression but no test targets. The prompt explicitly prohibited code, calculators, and regression, and required one number only. It could not invoke the fitted model. A no-RAG arm asked the same model the same questions without reference rows.

The LLM+RAG MAE was about $8.1$ times the regression MAE. In this run, the LLM's MAE was 70.95\% lower with RAG than without it (107.15 versus 368.82; no-RAG predictions 100, 1500, 1000), but remained far less accurate. Cases 1--2 exactly match retrieved revenues, consistent with copying and not evidence of learned regression behaviour. Retrieval returned overlapping rows rather than consistently near temperatures: every case included 0.98 and 25.24. At 40.47, it returned 0.98, 25.24, and 21.28 although 32.89 and 45.00 were available. Regression instead estimated a global linear trend from all training rows. Three cases cannot support broad statistical claims, and the deliberately even reference sample limits generalisation.

\subsection{Later controlled small-model code-generation experiment}
After teacher feedback, we narrowed the study to the same small local model without RAG versus with RAG. This experiment asks whether the model can \emph{generate a runnable regression program}; it does not repeat the direct numerical-prediction protocol. Within each pair, model, dataset, instruction, 4T fields, temperature 0.2, and context 16,384 were fixed; only \texttt{top\_k} changed from 0 to 4. Retrieval used \model{embeddinggemma} over a frozen lean corpus of 566 chunks (12 selected scikit-learn files and seven project guides). Generated notebooks were executed unchanged with a 60-second timeout.

None of the six programs ran (\textbf{0/6}); consequently, assigning them prediction errors would be invalid. The hand-written baseline did run and had previously recorded MAE 20.3146 over all 75 ice-cream test rows---a different denominator from the three selected rows in Table~\ref{tab:predictions}, but drawn from the same test set. In the two 1B RAG runs, the model copied a worked example's placeholder \texttt{data.csv} despite an explicit dataset block giving the real path and forbidding that substitution. These controlled outcomes concern task completion, not a claim that RAG universally harms coding.
